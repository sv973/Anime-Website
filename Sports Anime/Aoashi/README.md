# AO ASHI Fan Site

A responsive Ao Ashi themed fan-site built with:
- HTML
- CSS
- Vanilla JavaScript

## Features
- Ao Ashi / Tokyo City Esperion visual theme
- Responsive layout
- Player cards
- Click-to-expand player descriptions
- Story section
- Esperion pitch graphic
- Mobile navigation-ready structure

## Run it
Open `index.html` in a browser.

## Images
The demo uses remote image URLs so the site works immediately. For a public/commercial site, replace those with image assets you have permission to use.

Character information was based on the official Ao Ashi character pages.
